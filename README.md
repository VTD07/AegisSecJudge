# Python_test_checker
Trình check test sử dụng ngôn ngữ python (hỗ trợ cho c++ và py)
Lưu ý: 
- folder chứa test cần được đặt tên là test_folder
- Folder chứa file C/C++ sẽ được để cùng một chỗ do có chung một bộ dịch
- Các folder chứa code sẽ được đại diện bằng tên ngôn ngữ đó
- Có 2 folder: pending và proccessed - đang chờ xử lý và đã xử lý
- Folder pending: chứa các file code đã được phân loại sẵn trên ngôn ngữ 
- Folder proccessed: chứa các file code đã được phân loại thành các trường hợp: AC, RTE, TLE, WA
